在庫 × 配送データ ツール

① 在庫の減り方が請求書の配送数量と合っているか確認する機能と、② 現在庫から配送後の在庫数を作る機能をまとめています。請求書にしかないIDは無視し、在庫表にあるポケカPSAだけを対象にします。

① 在庫増減データ

A=カード名 / B=ID / C=在庫上限 / D=減らす前 / E=減らした後
「在庫1」「在庫0」の表記にも対応。

① 現在庫データ

推奨：A=カード名 / B=ID / C=在庫上限 / D=現在庫
5列貼り付けた場合は、E列に数値があればEを現在庫として使用します。「在庫2」表記もOK。

② 今日の配送・請求データ

A=ID / B=カード名 / C=数量
同じIDが複数行なら数量を合算して差し引きます。現在庫側にないIDは無視します。

減少後在庫だけ（1列コピー用）

現在庫シートの並び順・行数をそのまま維持します。配送がない商品は現在庫の数字をそのまま残し、現在庫が空欄の行は0として残します。この欄をコピーして、減少後在庫を入れたい列の先頭セルへそのまま貼り付けできます。

確認用（A:E）

カード名 / ID / 在庫上限 / 現在庫 / 配送後在庫 の5列です。現在庫シートの順番を維持しています。
